# DEBUG 2026 — дизайн спецификациясы

Мектеп оқушыларына арналған онлайн кодинг жарысына тіркеу беті.
Бір бетті, бір тақырыпты (dark-only), қазақ тілді.

---

## 1. Концепция

**Сайттың өзі — дебаггер сессиясы.**

Метафора декорация емес, құрылымды анықтайды:

| Дебаггердегі нәрсе | Беттегі рөлі |
|---|---|
| Gutter (жол нөмірлері) | Сол жақтағы тұрақты рейл |
| Breakpoint нүктесі | Скролл прогресін көрсететін маркер |
| Синтаксис бояуы | Тақырыптағы глитч, `//` комментарий-жапсырмалар |
| Терминал сессиясы | Тіркелу формасы (`./register.sh`) |
| Консоль шығысы | Қатысушылар тізімі (`[0042] Аты Жөні`) |
| Paused process | Кері санақ (жарыс басталғанда «resume») |

**Эмоциясы:** тыныш, дәл, техникалық. Ойын емес — құрал.
**Болдылық бір жерде ғана:** мята-циан акцент. Қалғаны үнсіз.

## 3. Типографика

### Гарнитуралар
| Рөлі | Гарнитура | Салмақтар |
|---|---|---|
| Дисплей + бүкіл интерфейс | **JetBrains Mono** | 300 / 400 / 500 / 700 / 800 |
| Лид абзацтар ғана | **IBM Plex Sans** | 300 / 400 / 500 |

```
--mono: "JetBrains Mono", ui-monospace, SFMono-Regular, Menlo, Consolas, monospace
--sans: "IBM Plex Sans", "Noto Sans", system-ui, -apple-system, sans-serif
```

Бет **mono-үстем**. Пропорционал шрифт тек 2–3 ұзын абзацта — оқылымдылық үшін. Бұл әдейі жасалған контраст: құрылымның бәрі «код», тек түсіндірме мәтін «адам тілі».

Fallback-те `Noto Sans` тұр — қазақ әріптері (ә ғ қ ң ө ұ ү һ і) жетіспей қалған жағдайға.

### Масштаб
| Элемент | Өлшемі | Аралық | Салмақ |
|---|---|---|---|
| Алып тақырып `DEBUG` | `clamp(66px, 17.5vw, 206px)` | `-.05em`, line-height `.86` | 800 |
| Statement (акт 2) | `clamp(30px, 7.4vw, 66px)` | `-.035em`, lh `1.08` | 500 |

| Үлкен сан (қатысушы) | `clamp(44px, 11vw, 86px)` | `-.05em`, lh `.9` | 800 |
| Countdown цифры | `clamp(26px, 6vw, 34px)` | `-.02em` | 700 |

| Терминал жолы | `13.5px` / lh `1.85` | — | 400 |

### Ережелер
- Барлық сандар (`countdown`, есептер, `[0042]` индекстер): `font-variant-numeric: tabular-nums`
- Тақырыптар: `text-wrap: balance`; лид: `text-wrap: pretty`
- Лид ені: `56ch`-тен аспайды; statement: `17ch`
- Kicker-дің алдында әрқашан `//` (`::before`, түсі `--dim`) — бұл код комментарийі, декоративті сызық емес

## 4. Кеңістік және пішін

```
--pad:  clamp(20px, 5.5vw, 72px)   бүйір шегініс
--rail: 58px                        сол жақ gutter ені (<900px-те 0)
контент максимумы: 1180px
секция үсті: clamp(72px, 11vw, 140px)
```

| Radius | Қайда |
|---|---|
| `18px` | Панель |
| `14px` | Терминал, roster |
| `12px` | Countdown торы |
| `11px` | Батырма, input |
| `999px` | Chip |

**Барлық жиек 1px.** Көлеңке үнемді: тек терминалда `0 40px 90px -50px #000` және акцентті батырмада glow. Card-тар бір-біріне ұқсас штампталмайды — жиек/фон/көлеңке рөл бойынша беріледі.

## 5. Қабат стегі (z-index)

Түпнұсқа сайттағыдай — бекітілген атмосфера қабаттары, мазмұн олардың үстінде жүзеді.

```
0  --z-ground   .ground   fixed градиент (радиал + линейр) + blur(52px) aurora жолағы
1  --z-rain     <canvas>  код жаңбыры, opacity .24, жоғары/төмен mask-fade
2  --z-scan     .scan     сканлайн, repeating-linear-gradient 1px/3px, opacity ~.014
3  --z-grain    .grain    SVG feTurbulence шуы, opacity .05, mix-blend-mode: overlay
4  --z-content            секциялар, акттар, gutter, оң рейл
8  --z-chrome   .topbar   бекітілген жоғарғы жолақ
```

### Ground рецепті
```css
background:
  radial-gradient(120% 70% at 50% -6%, rgba(52,224,196,.10), transparent 58%),
  radial-gradient(90% 60% at 88% 108%, rgba(155,123,255,.07), transparent 62%),
  linear-gradient(#0B1219, #080E15 34%, #070B10 72%, #05080C);
```
`::after` — диагональ aurora жолағы, `inset:-20%`, `filter: blur(52px)`, alpha .05–.09.

### Grain рецепті
```
inline SVG: feTurbulence type="fractalNoise" baseFrequency=".85" numOctaves="3"
140×140 плитка, opacity .05, mix-blend-mode: overlay
```

## 7. Компоненттер

### 7.1 Topbar
Бекітілген, төмен қарай өшетін градиент фон (`rgba(7,11,16,.86) → 0`) + `blur(2px)`.
Сол жақта: `DEBUG` (800, `.16em`, циан) + `2026` (400, 10px, dim).
Оң жақта екі chip: тірі есеп (импульсті циан нүктемен) және `05.09 · 14:00`.

**Chip:** 1px hairline, radius 999, padding `6px 13px`, 11px, `.08em`, фон `rgba(14,22,32,.62)`.

### 7.2 Kicker
```
[//] ЖАПСЫРМА МӘТІНІ
```
`::before { content:"//" }` түсі `--dim`, өзі `--accent`, 11px, `.14em`, uppercase, төменгі шегініс 20px.

### 7.3 Алып тақырып + глитч
`DEBUG` + жыпылықтайтын `_` курсор (циан, 1.15s steps(1)).
Глитч: екі `::before/::after` көшірмесі — қызғылт (`--err`) `-3px` солға, циан (`--accent`) `+3px` оңға. Екеуі де тыныш күйде `clip-path: inset(100% 0 0 0)` — көрінбейді. 8 секундтық циклдің тек 88–100% аралығында `steps(1)` арқылы 3 рет жыпылықтайды.

> Маңызды: глитч үздіксіз жүрмейді. Сирек болғандықтан ғана әсерлі.

### 7.4 Countdown
4 бағанды grid, `gap: 1px`, фоны `--hairline` — бұл жалған жиектер жасайды.
Әр ұяшық: `--panel` фон, padding `15px 8px 12px`, цифр `--warn` түсті, астында 9.5px dim жапсырма.
Нөлге жеткенде: `.is-live` класы — цифрлар цианға ауысады, kicker «ЖАРЫС БАСТАЛДЫ» болады.

**Мақсат уақыты:** `2026-09-05T14:00:00+05:00`

### 7.5 Панель
```
1px hairline · radius 18 · фон rgba(14,22,32,.56) · backdrop-filter blur(6px)
box-shadow: inset 0 1px rgba(52,224,196,.10)   ← жоғарғы жиектегі жарық
padding 26px 24px 24px · max-width 560px
```

### 7.6 Батырмалар
**Primary** — циан фон, `#04120F` мәтін, 700, `.08em`, min-height 52, radius 11.
`hover` → `#5BEBD4` + glow. `active` → `translateY(1px)`. `disabled` → alpha .28.

**Ghost** — тек астыңғы 1px сызық. `hover`-де сызық цианға ауысады **және `gap: 9px → 15px`** — жебе алға жылжиды. Бұл түпнұсқа сайттан алынған микро-әрекет.

### 7.7 Терминал терезесі
```
┌─────────────────────────────────────────┐
│ ● ● ●  ~/debug-2026/register.sh         │  ← term-bar
├─────────────────────────────────────────┤
│ $ ./register.sh --event=debug-2026      │  ← теру анимациясы
│ > Аты-жөніңді енгіз…                    │
│                                          │
│ АТЫ-ЖӨНІ                                │
│ [____________________________]           │
│ [        ҚАТЫСАМЫН           ]           │
│ хабар жолы                               │
└─────────────────────────────────────────┘
```
- Үш нүкте: `#FF5C7A` / `#F2A93B` / `#34E0C4` — 8px
- Жол: `$` prompt циан, `--event=` бөлігі күлгін (`--violet`)
- Теру: `steps()` арқылы `width: 0 → Nch`, 1.1s. Мәтін DOM-да толық тұрады (reduced-motion-де бірден көрінеді)
- Фон: `rgba(10,16,23,.78)` + `blur(8px)`

### 7.8 Input өрісі
Жапсырма 10.5px `.16em` uppercase циан. Өріс: min-height 54, radius 11, фон `rgba(6,10,15,.66)`, 1px hairline, 16px mono.
`focus` → циан жиек + `0 0 0 3px rgba(52,224,196,.10)` сақина.
`.has-error` → `--err` жиек.

### 7.9 Қатысушылар консолі
Жоғарыда: үлкен сан (800, tabular) + `ОҚУШЫ ТІРКЕЛДІ` жапсырмасы.
Тізім жолы:
```
[0042]  Айсұлу Жақсылық
   ↑ 11.5px dim, min-width 52px    ↑ 13.5px muted
```
Өз жазбаң: фон `rgba(52,224,196,.07)`, аты циан.
Тізім биіктігі 302px, ішкі скролл (жіңішке, `--hairline` түсті). Астында foot: `registry · live` ↔ `N жазба`.

### 7.10 Ақпарат кестесі (dl)
Жоғарғы 1px hairline. Әр жол: 22px padding, астыңғы hairline.
`≥760px`-те `220px 1fr` екі баған, кіші экранда бір баған.
`dt` — 10.5px `.16em` uppercase циан. `dd` — 17px. `dd small` — 12.5px dim, 5px үстінде.

### 7.11 Gutter (сол рейл)
Ені 58px, оң жағында `--hairline-soft` 1px, фоны сол жақтан оңға өшетін `rgba(6,10,15,.72) → 0`.
26 жол нөмірі (`01`…`26`) біркелкі таралған, 10px, dim, opacity .5, оңға туралау.
**Breakpoint:** 9px қызғылт дөңгелек, `box-shadow: 0 0 0 3px rgba(255,92,122,.16)`, `top` мәні беттің скролл прогресіне сәйкес жылжиды.

### 7.12 Оң рейл
`writing-mode: vertical-rl`, 10px, `.34em`, dim: `DEBUG // 05.09.2026`.

## 8. Анимациялар

**Бүкіл сайтта бір ғана easing:** `cubic-bezier(.22, 1, .36, 1)` (expo-out).
Ұзақтығы: интерфейс 0.18–0.32s, атмосфера 1.1–8s.

| Аты | Не істейді | Параметрлері |
|---|---|---|
| **Акт кросс-фейд** | 300vh скроллда үш кадр ауысады | акт1 `1 → 0` (p .20–.33), акт2 `0 → 1 → 0` (p .35–.45, .58–.69), акт3 `0 → 1` (p .71–.81). Қосымша `translateY((1-o)*14px)` |
| `blink` | Курсор `_` | 1.15s `steps(1)` шексіз |
| `g1` / `g2` | Тақырып глитчі | 8s `steps(1)`, тек 88–100% белсенді |
| `drift` | Скролл нұсқағыш сызығы | 2.8s. `scaleY .35↔1`, ортасында `transform-origin` top↔bottom ауысады |
| `pulse` | Topbar-дағы тірі нүкте | 2.6s, `box-shadow` 0→7px таралады |
| `typing` | Терминал жолы | 1.1s `steps(N, end)`, `width: 0 → Nch` |
| **Код жаңбыры** | Canvas | 30fps шектеу, әр кадрда `rgba(7,11,16,0.11)` бүркеу (із қалдырады) |

### Код жаңбырының нақты параметрлері
```
таңбалар:  01{}[]()<>;=+-*/!&|?:._#$abcdefxyzλƒ→ӘҒҚҢӨҰҮҺІ
баған ені: 17px       жол биіктігі: 16px
жылдамдық: 7–27 жол/сек (әр бағанда кездейсоқ)
белсенді:  бағандардың ~44%-ы ғана (сирек, тығыз емес)
түсі:      88% циан · 5% күлгін · 4% кехрибар  ← сирек «синтаксис» жарқылы
canvas opacity: .24, жоғары/төменнен mask-fade
```
Қазақ әріптерінің араласуы — жергілікті деталь, matrix клишесінен ажыратады.

### prefers-reduced-motion
Барлық анимация 0.001ms-ке түседі; жаңбыр бір статикалық кадр ретінде салынады (бос экран қалмайды); глитч мүлде өшеді; теру эффектісі толық мәтінге ауысады.

## 9. Күйлер

### Тіркелу формасы
| Күй | Көрінісі |
|---|---|
| idle | Форма ашық, хабар жолы бос |
| валидация қатесі | `! аты-жөні кемінде 3 таңба болуы керек` — `--err`, өріс жиегі қызғылт |
| дубликат | `! бұл ат тізімде бар` |
| жіберілуде | `> тексерілуде…` → `> тізімге жазылуда…` (циан), батырма disabled |
| сәтті | Форма жасырылады, орнына үш ✓ жолы шығады |
| желі қатесі | `! Сақталмады. Қайталап көр.` |

**Сәтті блок:**
```
✓ тіркелді: Айсұлу Жақсылық
✓ қатысушы нөмірі: #0042        ← --warn түсті
✓ жарыс сілтемесі басталар алдында жіберіледі
   Қатысушылар тізімі →
```

### Дерек көзі
- **Тірі режим** — тізім барлық көрушіде бір мезетте жаңарады. Ескертпе: «Тізім тікелей эфирде жаңарып отырады.»
- **Жергілікті режим** — дерекқор қолжетімсіз болса, тізім тек сол браузерде сақталады. Ескертпе: «Жергілікті режим: тізім тек осы браузерде сақталады.» Форма өшірілмейді.

## 11. Адаптив

| Шек | Не өзгереді |

| `≥760px` | dl екі бағанға (`220px 1fr`) ауысады |

`clamp()` барлық ірі типографияда — бөлек mobile өлшемдері қажет емес.

## 12. Қолжетімділік

- `:focus-visible` — 2px циан контур, 3px offset, radius 4
- Хабар жолы `role="status" aria-live="polite"`
- Барлық декоративті қабат `aria-hidden="true"` + `pointer-events: none`
- `prefers-reduced-motion` толық қолдау (§8)
- Мәтін/фон контрасты: `--text` үстінде `--ground` ≈ 14:1; `--muted` ≈ 5.4:1; `--dim` тек ұсақ метадеректерде
- Акттардың `pointer-events` мәні `opacity > 0.6` болғанда ғана `auto` — көрінбейтін қабат басып қалмайды

## 13. Ескерілмеуі керек әдеттер

Бұл жоба әдейі болдырмайтын нәрселер:

- ❌ Барлық блокқа бірдей radius + көлеңке штампы (иерархияны жояды)
- ❌ Үздіксіз жүретін глитч немесе тығыз matrix жаңбыры (арзан көрінеді)
- ❌ `#00FF00` matrix жасылы немесе таза `#000` фон
- ❌ Эмодзи секция маркерлері, ортаға туралаған бәрі
- ❌ Акценттің үш түсін бірдей еркін қолдану — әрқайсысының бір ғана мағынасы бар
- ❌ 01/02/03 нөмірленген маркерлер (мазмұн тізбек емес). Gutter нөмірлері — бөлек әңгіме: олар «файл» метафорасының шын бөлігі
